# Тест: Какой департамент ONE! City?

## О проекте

Интерактивный тест-определитель департамента для участника лагеря **«ONE! City»**. По результатам прохождения теста пользователь узнаёт, какой департамент ему подходит (Инженерный штаб и другие).

## Как работает

1. Откройте `index.html` в браузере.
2. Ответьте на серию вопросов.
3. Получите результат — рекомендацию департамента.

## Как открыть

Откройте файл `index.html` в любом современном браузере — сервер не требуется.
